# 컷신 (인트로 · 보통 모드 새 판 시작 · 100층 엔딩)

- 게임을 켜면 **인트로** (약 21초): 밤샘 야근 → 책상에 떨어진 "구조조정까지 D-30" 통보 → 화가 치밀어 통보를 구김 → 창가에서 빌딩 꼭대기를 올려다보며 "이 회사를 통째로 날려 버리겠어" → 제목
- 보통 모드 새 판마다 **시작 컷신** (약 6.5초, Enter·Esc·Space·클릭으로 건너뜀): 통보 → 창가의 주먹 → "업무 시작!"
- 보통 모드 100층 **엔딩** (약 19초): CEO실 → 책상 앞에서 손을 듦 → 책상 위 손바닥만 한 폭파 버튼을 누르는 손 가까이 → 빌딩 폭발 → 책상에서 깨어남(꿈) → 다시 D-30 통보 → 결과 화면
- 그림체는 참고 영상(밤 사무실, 청록 하늘, 슬레이트 빌딩의 작은 노란 창, 검은 양복 실루엣의 하얀 테두리 빛, 원근으로 누운 통보)을 따른다. 움직임은 피자 타워식(예비 동작 → 넘쳤다 돌아오는 팝, 스미어, 충격 번쩍·흔들림, 눌림)
- 소리 효과는 자막으로 쓰지 않는다 (자막은 말과 설명만)

| 파일 | |
|---|---|
| `make_cutscenes.py` | 그림 만들기 (배경 12장, 시트 6개, 2배 밀도) → `demo_api/assets` + sprite_definition. `python tools/cutscenes/make_cutscenes.py demo_api/assets <NotoSansKR-Bold.ttf>` |
| `make_cs_sounds.py` | 컷신 소리 9개 (타자, 종이, 도장, 화남, 휙, 버튼, 폭발, 자명종, 제목) |
| `cs_gallery.py` | QA 갤러리: `?cs=<id>&cst=<초>&csfreeze=1`로 멈춘 화면을 간격마다 찍어 한 장으로 |

대본(장면·카메라·배우 키·자막·효과)은 `demo_api/game.js`의 `CUTSCENES` (Unity는 `GameController.Cutscenes`). 규칙 검사는 `tools/qa/cutscene_qa.js`.
